## How to use this section

Use these pages as templates when documenting your API:

- Provide accurate request/response examples.
- Include sample code in multiple languages.
- Use consistent formatting for parameters and payloads.
- Document authentication and authorization clearly.
- Provide error messages and troubleshooting tips.
- Keep all examples up to date with your real API.
