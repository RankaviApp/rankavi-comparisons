## Example requests

Show developers exactly how to authenticate in different languages.

<Tabs>
  <Tab title="cURL">
    ```bash
    curl -X GET "https://api.yourdomain.com/v1/resource" \
      -H "Authorization: Bearer YOUR_API_TOKEN"
    ```
  </Tab>

  <Tab title="JavaScript">
    ```javascript
    fetch("https://api.yourdomain.com/v1/resource", {
      headers: { Authorization: `Bearer ${YOUR_API_TOKEN}` }
    });
    ```
  </Tab>

  <Tab title="Python">
    ```python
    import requests
    requests.get(
      "https://api.yourdomain.com/v1/resource",
      headers={"Authorization": "Bearer YOUR_API_TOKEN"}
    )
    ```
  </Tab>
</Tabs>
